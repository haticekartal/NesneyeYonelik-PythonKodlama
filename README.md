# Nesneye Yönelik Python Kodlama

Python programlama derslerinde yazılan örnek kodlar. Kodların tamamında Türkçe açıklama satırları bulunur.

## Kurulum

Bilgisayarınızda Python 3.10 ya da daha yeni bir sürüm kurulu olmalıdır. Kontrol etmek için terminale şunu yazın:

```bash
python --version
```

Python kurulu değilse [python.org](https://www.python.org/downloads/) adresinden indirebilirsiniz. Örnekler için ek bir kütüphane kurmanız gerekmez.

## Çalıştırma

```bash
git clone https://github.com/haticekartal/NesneyeYonelik-PythonKodlama.git
cd NesneyeYonelik-PythonKodlama/modül2/hafta1
python degisken_tanimlama.py
```

## Konular

- Python kurulumu, editör ve IDE kullanımı
- Değişkenler, sabitler ve veri tipleri
- Operatörler ve işlem önceliği
- Karar yapıları: `if-else`, iç içe koşullar, `match-case`
- Döngüler: `for` ve `while`
- Veri yapıları: liste, yığın, kuyruk, tuple, küme, sözlük
- Fonksiyonlar: parametreler, `return`, global ve yerel değişkenler
- Dosya işlemleri: oluşturma, okuma, yazma, silme
- XML ve JSON
- Sınıflar: metotlar, `__init__`, sınıf metotları ve statik metotlar
- İsim uzayları ve `import`
- Kalıtım ve çoklu kalıtım
- Veritabanı işlemleri
- Thread kullanımı
- Ağ işlemleri: `urllib` ve `socket`
